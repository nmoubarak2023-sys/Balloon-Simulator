BALLOON BUILD / QUICK START

From boundary to balloon field.

  1. Explore the demo, or import a closed Rhino mesh, STL, or OBJ. Choose a boundary if the file has several meshes.
  2. Set count, seeds, and radius range. Generate balloons.
  3. Choose CURVE POINTS. Click and drag a point in either canvas, or use its X/Y/Z arrows in 3D. Pressure updates when you release the point.
  4. Choose MOVE BALLOON and drag any balloon directly, or use its axis arrows. SCALE BALLOON provides uniform scale handles. On release, edits are limited to safe positions inside the wall and away from neighbors.
  5. Build shell assembly or Boolean subtraction, then export. Save a project to preserve geometry and settings.

ROTATE BOUNDARY rotates the actual imported mesh around its center. Select X, Y, or Z and enter exact degrees or choose a 90° / 180° preset. The rings snap to 90° by default; Ring snap also offers 15°, 45°, or Free. Rotation regenerates the balloon field and resets individual edits. Curve-point drags also regenerate the field and reset individual edits. Use ORBIT, or drag empty space, to change only the camera.

This is geometric form finding, not a physical material simulation. Solid intersections and separating contact planes prevent overlapping balloon volumes. Crowded fields can create small or empty cells; these are reported.

The browser solver reinterprets the Grasshopper workflow using a different random generator and a solid geometry kernel. It does not execute RhinoCommon or reproduce the definition exactly.

Shell assembly preserves separate shells in one mesh. It is not a union or a single solid. Boolean output is checked for valid, closed, manifold topology. Failed checks show warnings but do not block mesh export when a Boolean result exists. Exporting does not repair the mesh. Models are processed locally.

Helvetica Neue LT Pro is used when installed, with Helvetica Neue, Helvetica, and Arial fallbacks. A licensed webfont can be added later.
